# n8n Projects

A collection of my automation workflows and AI agents built with [n8n](https://n8n.io), the open-source workflow automation tool.

## What's inside
Each workflow is exported as a JSON file that you can import directly into n8n. Projects focus on:
- AI agents and multi-agent systems
- Messaging bots (Telegram, WhatsApp)
- Integrations with Gmail, Google Calendar, Google Sheets, and more

## How to use a workflow
1. Open your n8n instance
2. Go to **Workflows** → **Import from File**
3. Select the workflow's `.json` file
4. Connect your own credentials (OpenAI, Google, Telegram, etc.)
5. Activate the workflow

> Credentials, API keys, and personal IDs are removed from all workflows. You need to add your own.

## Projects
- **Telegram Multi-Agent AI Assistant**: text, voice, and image assistant on Telegram using MCP agents
- **WhatsApp Multi-Agent AI Assistant**: text, voice, and image assistant on WhatsApp with Gmail, Calendar, web search, and Sheets agents
